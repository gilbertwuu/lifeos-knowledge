# Knowledge base instructions

This folder is the vault root.

- Before starting a task, consider whether the vault can supply relevant context, a method, or past experience. When it can, start with `INDEX.md`, read the relevant notes, and trace their sources as needed. Continue with the task if nothing applies.
- When asked to save knowledge, read `MEMORY.md`, check `INDEX.md` for related entries, and follow the vault's capture workflow. Report the saved note and its source.
- Images are optional. When illustrating a note, keep the text usable on its own and verify the relative image path.
- The `examples/` folder demonstrates the format. Populate the index and collaboration profile with your own material.
