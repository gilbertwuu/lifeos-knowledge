# Daily knowledge capture

Use 23:50 in your chosen time zone as a starting point. Try the prompt in a test vault first, then create a scheduled task in Codex. Record the allowed sources, vault, and checkpoint location.

## Copyable prompt

> Use the LifeOS knowledge base Skill to capture durable knowledge from today's conversations. Vault <absolute path>. Time zone <IANA time zone>. Authorized inputs <specific chats, record paths, and dates>. Checkpoint <state directory>. Read MEMORY.md, INDEX.md, and the prior checkpoint. Use message timestamps to find today's new messages, including new activity in older chats. Use authorized user messages and visible answers. Revisit unresolved gaps within the authorized scope. Screen for lasting value, deduplicate by substance, and save Sources, Notes, or Wiki entries under the vault rules. Verify the index and attachments. Report changed paths, coverage, gaps, and what to revisit. Leave the vault alone when there is no new material worth saving.

## Check the first run

Include one useful source you can trace and one duplicate. Verify the new or updated note, source, index, and checkpoint. Check the time zone, vault, and output location on the first scheduled run. Use the same task settings to pause, resume, or reschedule.
