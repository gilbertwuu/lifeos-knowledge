# LifeOS 知识管理

在 Codex 桌面端选择 LifeOS 知识管理插件，在新对话中调用下列入口。准备 Python 3.11 或更新版本。知识库目录由你指定，Obsidian 可打开同一个文件夹。

1. **知识库搭建与使用**。告诉 Codex 你要新建或接入的文件夹。建库后打开[接入说明](skills/lifeos-knowledge-base/assets/vault/接入说明.md#一让-codex-在日常任务中参考知识库)，把调用规则加到生效的 `AGENTS.md`。希望每个项目都参考，就放进 Codex 全局规则。只希望一个项目参考，就放进那个项目的规则。换个新对话，用普通任务验证接入。
2. **知识复用统计**。提供知识库、时区、日期和允许读取的 Codex 记录范围。先核对预览，再确认入账。日明细与周回顾证据可在库内 `.lifeos/` 或选择的状态目录保存。
3. **Skill 沉淀周回顾**。选定一周，比较真实任务里的重复步骤和已安装的 Skill，得到改进建议。

## 定时任务配置指南

- [每日知识沉淀](guides/01-每日知识沉淀.md)

三份指南均可先在测试库手动运行，再由使用者通过 Codex 的自动化入口配置。首版统计支持选定 Codex JSONL 里的显式单文件 `cat` 读取。复用计数采用真实读取事件，周回顾另行核对独立任务与实际做法。报告标明可见记录范围与待核项。
