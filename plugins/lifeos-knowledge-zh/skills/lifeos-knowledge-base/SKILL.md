# 知识库搭建与使用

从用户指定的路径、当前库或已生效的项目规则确定本次使用的知识库。路径冲突或权限不足时说明具体位置。已有库的 `MEMORY.md` 与 `AGENTS.md` 决定维护和调用规则。

## 建库

用 Python 3.11 或更新版本运行本 Skill 的 `scripts/init_vault.py`，参数为使用者选定的知识库文件夹。它从 `assets/vault/` 补齐缺少的文件。已有同名文件保留，文件和目录冲突时先核对。结束时检查 `AGENTS.md`、`MEMORY.md`、`INDEX.md` 以及示例的相对图片路径。跨项目接入和 Obsidian 使用见模板里的 `接入说明.md`。

交回建库结果时，给出库路径、模板 `接入说明.md` 的链接和可复制的调用规则。说明要在库外的日常任务中主动查库，需要将规则追加到生效的全局或项目 `AGENTS.md`。如果已有知识库保留了旧版接入说明，使用本 Skill 附带的最新版给出接入步骤。用户指定目标文件并要求接入时，先读已有规则，再以最小改动合并。

## 保存

1. 读取库规则与索引，核对用户指定的原文和来源。
2. 判断内容的复用价值与成熟度。先读相关旧条目，比较具体结论、依据和适用条件。
3. 无新增就跳过。新证据优先补到旧文，原始资料、暂未成熟的想法与可独立复用的知识分别按库规则入 Sources、Notes 与 Wiki。
4. 写清具体认识、来源和适用范围。有证据的关系才链接。用户已有的协作偏好按授权记录。
5. 核对正文、来源、索引与附件。交回实际保存位置和仍缺的证据。

每日沉淀的输入范围、增量判断和检查点见插件根目录 `guides/01-每日知识沉淀.md`。可用的漫画 Skill 是可选能力，只有实际存在图片时才写图片引用。

## 调用

从 `INDEX.md` 找直接相关条目，再读正文并按需要追溯来源。将适用的知识用到实际判断、写作或操作中，继续查证当前任务所需事实。找不到匹配条目时如实说明并继续完成任务。个人协作档案按当前任务和库内规则查用。

如使用复用统计，Codex 通过一次单文件 `cat` 实际返回被参考笔记的正文，可以在本地记录中留下首版采集器能够识别的请求和返回。用实际工作所需的读取即可，统计回放自身不入账。
