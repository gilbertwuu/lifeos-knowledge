# 用 Agent 保存知识，在 Obsidian 读图文

## 一、让 Codex 在日常任务中参考知识库

建库会生成库内的 `AGENTS.md`，供从库目录打开的 Codex 对话使用。`MEMORY.md` 说明怎样入库，`INDEX.md` 用来定位已有知识。

希望在知识库以外的项目中也能主动调用，按使用范围选择要追加规则的文件。

- **所有项目**。在 Codex 全局规则文件中追加，默认位置是 `~/.codex/AGENTS.md`。如果使用自定义 Codex 主目录，以实际目录为准。
- **一个项目**。在那个项目根目录的 `AGENTS.md` 中追加。
- 如果对应位置有生效的 `AGENTS.override.md`，就在该文件中追加。目标位置没有规则文件时可以新建 `AGENTS.md`。

复制下面这段，将占位符换成你电脑上的知识库绝对路径，保留文件里原有的规则。

```markdown
## 我的知识库
知识库根目录为 `<我的知识库文件夹的绝对路径>`。
每次开始任务前，先判断知识库是否能提供相关的背景、方法或经验。有明确用途时，先查该目录的 INDEX.md，再读直接相关的笔记正文，把适用内容用到当前任务中，并简短说明笔记及其作用。找不到适用笔记时继续完成任务。
当我说“保存这个”“沉淀到知识库”时，先读取该目录的 AGENTS.md 和 MEMORY.md，再查 INDEX.md 并按库内规则整理。
需要查库但路径或权限有问题时，说明具体缺口。
```

**检查接入。** 从希望使用知识库的项目新开 Codex 对话。挑一项与库中已有笔记相关的日常任务，只提出任务本身。比如库里有一篇关于区分观察与推断的笔记，可以问“这组用户反馈支持哪些判断？”查看 Codex 是否主动读取索引和相关笔记，并在分析里用上笔记的方法。若没有查库，可以先请它列出本次生效的规则和识别到的知识库路径。

## 二、可选的漫画配图

示例包含一张现成图片，用来检验阅读效果。如果希望生成新漫画，选择当前 Codex 环境可用的图像工具或漫画 Skill，先写清文章和需要解释的内容。图片保存到文章同级的 `附件/` 后再加相对路径。只准备文字时可以保留完整正文。

## 三、在 Obsidian 打开图文

打开 Obsidian，在仓库选择界面选“打开本地文件夹作为仓库”（Open folder as vault），选包含本说明的整个文件夹。在文件列表打开[观察和猜想要分开写](示例/观察和猜想要分开写.md)，切到阅读视图。你应该先看见一句话摘要，下面是一张漫画，再往下是正文和表格。

这篇笔记里实际用的写法是：
```markdown
![漫画学习卡：观察和猜想要分开写](附件/观察和猜想-wide-card.png)
```
复制笔记时连同旁边的 `附件/` 一起复制。若只显示文件名，检查链接前是否有 `!`；若出现缺图，检查图片是否真的在对应路径。资料库的 `INDEX.md` 留给使用者自己的内容，示例独立存放。
