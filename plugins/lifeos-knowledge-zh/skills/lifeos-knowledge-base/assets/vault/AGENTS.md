# 知识库协作入口

本文件所在目录是知识库根目录。

- 用户要求保存、沉淀或整理知识时，先读同目录的 `MEMORY.md`，再用 `INDEX.md` 找可能重复的条目。按维护规则保存，交回笔记入口与来源。
- 在开始任务前判断知识库是否能提供相关背景、方法或经验。有明确用途时先查 `INDEX.md`，再读相关正文并按需追溯来源。找不到适用笔记时，继续当前任务。
- 新建普通 Wiki 时，按 `MEMORY.md` 的配图约定调用 `comic-learning-card`。图像生成或文件访问不可用时，先交回完整正文，说明缺少哪一步。
- `示例/` 只用于演示显示效果。正式索引和个人协作档案由使用者自己的内容填充。
