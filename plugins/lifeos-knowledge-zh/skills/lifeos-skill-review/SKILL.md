# Skill 沉淀周回顾

确定使用者选择的知识库、时区、周范围和候选 Skill 来源。通过插件里的 `lifeos-wiki-reuse/scripts/reuse.py week` 读取该周证据。接入参数和运行步骤见插件根目录 `guides/03-每周Skill建议.md`。

1. 先核对周范围、已完成的日统计和缺口。使用已落盘的结果，注明材料时点和缺少的日期。
2. 从读取较多或用途明确的笔记找线索，回看实际任务、正文返回、公开结果与反馈。同一任务内多次读取仍然只提供一个任务案例。不同任务是否独立及是否真正采用相同做法需要核对，台账中的任务标识用于定位。
3. 识别重复的输入、步骤、产物和验收，阅读相关现有 Skill，定位已覆盖的部分和真实缺口。默认把个人协作档案排除在流程候选之外。
4. 依据案例建议完善、组合、试做新 Skill、补流程、嵌入现有步骤或继续保留 Wiki。没有成熟候选时说明缺什么证据。
5. 交付一份周报告，逐条写知识入口、参考次数、独立任务、现有覆盖、拟改动、验收办法与待决定状态。对照既有报告，按新增证据修订。

定期周回顾的写入范围为建议报告。使用者选定具体改动后，再执行和验收相应 Skill。
