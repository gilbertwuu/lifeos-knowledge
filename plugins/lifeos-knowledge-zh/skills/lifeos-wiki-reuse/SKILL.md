# 知识复用统计

确定知识库、时区、目标日期、授权记录来源及可写位置。先读取库规则和 `INDEX.md`。使用 Python 3.11 或更新版本执行本 Skill 的 `scripts/reuse.py`。精确调用示例见插件根目录 `guides/02-每日复用统计.md`。

1. `collect` 扫描使用者指定的 Codex JSONL 文件或目录，按正文返回时间归日。记录请求、返回、任务位置和覆盖缺口。候选只代表发现到的正文读取。
2. 回查候选的任务及当时的请求、返回，确认正文确为任务参考，写成 `审核.json`。格式为 `{"候选ID": "具体参考用途"}`。同一真实任务跨回合或跨记录延续时，可把值写成 `{"purpose": "实际用途", "task": "经核对的任务标识"}`，周回顾据此识别任务。需要人工复核的记录留待核。排除统计过程为了核对而重放的读取。
3. `review` 默认预览。用户要求入账或已授权例行写入时使用 `--apply`，更新台账和索引。按实际读取事件计数，真实重读分别计数，扫描同一原始调用只计一次。
4. 报告本次新增、目标日每篇次数与用途、全库累计和未覆盖范围。给出对应记录行号或核对入口。

首版采集器识别授权 JSONL 中能匹配到索引条目的单文件 `cat` 请求和实际返回。压缩、复杂工具、跨平台轨迹以及笔记正文变化后的旧返回需要另核。覆盖报告始终按部分记录处理。INDEX 只有既有计数、缺少对应台账时，先用独立库或迁移已有计数。
