# 每周 Skill 建议配置指南

以周一 09:30 为参考，回顾刚结束的一周。每天统计结果先落盘。已有 Dots 的使用者可把同一份任务说明交给 Dots 执行，先验证它能读取所选库、台账及案例，并核对其时区显示。选择一个执行入口。

## 可复制的任务说明

> 用 LifeOS Skill 沉淀周回顾 Skill 复盘〈知识库〉与〈状态目录〉在〈时区〉上一完整自然周的已确认记录。核对哪些日统计已经完成，标明材料截止时间。先从台账找线索，再读真实任务、公开输出及相关现有 Skill，确认独立案例里重复的步骤和实际缺口。把建议写到〈报告目录〉，逐项给出复用证据、处理理由、拟改范围、验收方式和待决定状态。定时任务的交付是周报告，具体改造由使用者决定。

## 手动执行与验收

```sh
python3 '<复用统计脚本路径>' --vault '<库路径>' --timezone Asia/Shanghai week --week 2026-W46
```

让当前 AI 根据周输出回查原记录和已有 Skill，并按周回顾 Skill 生成报告。先用两项独立真实任务确认是否有相同做法。日统计没完成时注明当前材料时点。对照已有建议和用户决定，有新证据再修订。首个定时周跑核对实际执行者、时区、读取的台账和报告落盘位置。通过所选宿主的同一任务入口暂停、恢复或改期。
