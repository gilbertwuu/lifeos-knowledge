# 每日复用统计配置指南

以使用者选定时区每天 09:00 为参考，回顾前一完整自然日。为待核证据和报告选一个状态目录，默认使用所选知识库内 `.lifeos/`。首先准备一项真实任务，明确调用库里的笔记，确认当时的工具请求及正文返回可读。

## 可复制的任务说明

> 用 LifeOS 知识复用统计 Skill 核对〈知识库绝对路径〉在〈时区〉前一完整日的参考读取。只扫描〈授权记录路径〉，将候选、审核和日明细保存到〈状态目录〉。检查原任务和实际正文返回，填写每条的真实参考用途，排除本统计为核对而做的回放。按原始读取事件去重。先预览，按当前已授权的写入范围更新台账和 INDEX。报告每篇次数和用途、本轮新增、全库累计与覆盖缺口。

## 手动执行与验收

从已加载的 Skill 找到 `scripts/reuse.py`。命令下列尖括号内容由使用者替换。可为多个已授权 JSONL 文件重复传入 `--record`，或传入经授权的 `--sessions` 目录。需要自定状态目录时，在子命令前追加 `--state-dir`。

```sh
python3 '<脚本路径>' --vault '<库路径>' --timezone Asia/Shanghai collect --day 2026-11-13 --record '<记录.jsonl>' --out '<候选.json>'
python3 '<脚本路径>' --vault '<库路径>' --timezone Asia/Shanghai review '<候选.json>' '<审核.json>'
python3 '<脚本路径>' --vault '<库路径>' --timezone Asia/Shanghai review '<候选.json>' '<审核.json>' --apply
```

审核文件示例为 `{"从候选取得的事件ID": "在该任务中采用的参考用途"}`。预览应保持索引原样。用同一批输入重跑，核对累计不再增长。记录中看不到正文或仅有索引路径时留待核。启用后核对一次真实触发、工作日期和目标库。通过宿主的同一任务入口暂停、恢复或改期。
